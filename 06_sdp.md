# Lakeflow Spark Declarative Pipelines

### Some recent changes to naming:
`Lakeflow Spark Declarative Pipeline` was formerly called `Delta Live Tables`
`import dlt` package has been replace with `import dp`
`@dlt` decorator has been replaced with `@dp`
`@table` decorator is used to create streaming tables
`@materialized_view` is used to create materialized views
